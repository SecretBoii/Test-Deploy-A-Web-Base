# Frontend Design

## เมื่อไหร่ควรใช้ Skill นี้
- ต้องการสร้างหน้าเว็บ/UI ที่มีความตั้งใจด้านดีไซน์ ไม่ใช่แค่ layout default
- ต้องการ landing page ที่ดูเป็นมืออาชีพสำหรับ product/บริการ

## สิ่งที่ Skill นี้ทำ
1. วางโครงสร้าง layout ตาม best practice ของหน้าประเภทนั้น
2. เลือก typography, สี, และ spacing ที่ตั้งใจ ไม่ใช่ default
3. สร้างเป็นโค้ดหน้าเว็บที่ใช้งานได้จริง

## ตัวอย่างการใช้งาน
```
ผู้ใช้: สร้าง landing page สำหรับ SaaS product
```
→ ได้หน้าเว็บที่มีดีไซน์ชัดเจน ไม่ generic
