# Skill Creator

## เมื่อไหร่ควรใช้ Skill นี้
- มี workflow ที่ทำสำเร็จบ่อยๆ และอยากแปลงเป็น skill ที่เรียกใช้ซ้ำได้
- Skill เดิมที่มีอยู่ trigger ไม่แม่น อยากปรับ description ให้ดีขึ้น

## สิ่งที่ Skill นี้ทำ
1. รับ workflow หรือ pattern การทำงานที่ต้องการแปลงเป็น skill
2. สร้างโครงสร้าง skill (instructions, knowledge, tools) ให้ครบ
3. ทดสอบและปรับ description ให้ trigger ตรงกับกรณีใช้งานจริง

## ตัวอย่างการใช้งาน
```
ผู้ใช้: อยากสร้าง skill ใหม่สำหรับสรุปรายงานตามฟอร์แมตของทีม
```
→ ได้ไฟล์ SKILL.md ใหม่ พร้อม instructions และตัวอย่างการใช้งาน
