# Web Design Guidelines

## เมื่อไหร่ควรใช้ Skill นี้
- ก่อนปล่อย UI ออกไปใช้งานจริง ต้องการเช็คคุณภาพตามมาตรฐาน
- ต้องการตรวจสอบ accessibility ของหน้าเว็บ/component

## สิ่งที่ Skill นี้ทำ
1. ตรวจสอบ UI ตาม Web Interface Guidelines
2. ตรวจ accessibility (contrast, semantic HTML, keyboard navigation ฯลฯ)
3. รายงานจุดที่ควรแก้ไข พร้อมข้อเสนอแนะ

## ตัวอย่างการใช้งาน
```
ผู้ใช้: review my UI for accessibility
```
→ ได้รายงาน audit พร้อมจุดที่ควรแก้ตาม guideline
