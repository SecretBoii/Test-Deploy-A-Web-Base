# Chart Visualization

## เมื่อไหร่ควรใช้ Skill นี้
- มีข้อมูลตัวเลข/ตาราง และต้องการภาพกราฟเพื่อสื่อสาร ไม่ใช่แค่ตัวเลขดิบ
- ไม่แน่ใจว่าควรใช้กราฟแบบไหนกับข้อมูลชุดนี้

## สิ่งที่ Skill นี้ทำ
1. วิเคราะห์โครงสร้างข้อมูลที่ให้มา (time series, categorical, comparison ฯลฯ)
2. เลือก chart type ที่เหมาะสมจากไลบรารี 26 แบบ (bar, line, pie, scatter, heatmap ฯลฯ)
3. Render เป็นไฟล์รูปภาพพร้อมใช้

## ตัวอย่างการใช้งาน
```
ผู้ใช้: มีข้อมูลยอดขายรายเดือน 12 เดือน อยากได้กราฟ
```
→ ได้กราฟเส้นแสดงแนวโน้มยอดขายตลอดปี พร้อมไฟล์รูปภาพ
