### 🧹 Coding Convention & PEP 8 Guidelines

Evaluate the structure and readability of the student's Python code following Python's style guide conventions:

1. **Naming Conventions:**
   - Functions and variable names must follow `snake_case` (e.g., `calculate_area`, `user_name`).
   - Constant values must follow `UPPER_CASE` (e.g., `PI = 3.14`).
2. **Spacing & Formatting:**
   - Ensure spaces are used around operators and after commas (e.g., `x = 5`, `a + b`, `print(x, y)`).
   - Avoid joining multiple statements on a single line using semicolons (`;`).
3. **Documentation:**
   - Check if basic comments or Docstrings are appropriately present where necessary to describe complex logic.
