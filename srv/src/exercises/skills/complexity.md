### Complexity & Performance Guidelines

Analyze the runtime efficiency and spatial characteristics of the student's code using computational and logic metrics:

1. **Time Complexity Analysis:**
   - Estimate the asymptotic time complexity of the solution using Big-O notation (e.g., $O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$).
   - Identify whether the student has introduced unnecessary nested loops or redundant execution passes.
2. **Suboptimal Loops:**
   - If the problem can be solved in linear time $O(n)$ or better, but the student uses a nested loop resulting in $O(n^2)$, suggest optimization techniques (e.g., using dictionaries/hash maps or sets instead of repetitive scanning).
3. **Space Complexity:**
   - Warn the student if they initialize large, unnecessary data structures (e.g., duplicate arrays or redundant matrices) that can be optimized.
